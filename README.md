## Pisces Online

Pisces is a sequencing tool provided by illumina. It is not easy to use for the non-CLI user, so this provides a simple web interface to be able to use the program from anywhere.

All that needs to be done by IT is:

1. Set up docker
2. Set up config.yaml (template in example_config.yaml is provided)
3. Run container 

And then you should be able to run default pisces commands (both to generate the collateral files, and to actually run the Pisces software)
